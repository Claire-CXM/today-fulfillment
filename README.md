# 今日兑现

一个手机优先的响应式 PWA 学习助手，帮助用户围绕“计划任务 → 专注倒计时 → 节点反馈 → 完成复盘”兑现每日学习目标。

## 当前版本

P1 功能增强版已实现：

- 任务清单、新建/编辑页和独立专注页分离
- 建议任务池每次展示三条，支持随机换一批、单条发布和全部发布
- 分钟/小时预计时长输入，最短 1 分钟
- 新任务与当天未完成任务的剩余总时长不可超过 24:00
- 同一时间仅允许一个任务进行中
- 基于真实时间戳的秒级专注倒计时、页面切换后连续计时、桌面画中画浮窗与通知降级
- 每任务普通暂停最多 3 次、累计最多 45 分钟
- 每任务最多十个可编辑节点，节点时长总和校验与自动进度
- 节点拆分完全可选；无节点任务不显示进度控件并支持直接完成
- 任务开始后锁定内容与节点，已完成任务保持只读
- 已开始任务支持二次确认后主动放弃，并永久保留在日总结与异常记录
- 完整月历、未来日期置灰及绿黄红紫状态圆点
- “今天 / 日历 / 复盘 / 奖惩 / 我的”手机底部导航结构
- 按任务总时长五分之一计算的一次性临期预警
- 可配置的督促风格、愧疚文案开关与减少动画设置
- 可配置每日提醒时间、用户主动通知授权与浏览器能力降级说明
- 自定义奖励池、完成后三选一领取、奖励记录与阶段奖励
- 独立奖惩模块、安全惩罚触发条件和完整记录
- 任务失败后一次本地规则审核、黄色待补和跨日期补做
- 日总结、本月进度与每月 1 日自动归档上月总结
- 每累计 7 个绿钩日解锁 1 张自由日卡
- Ionic 免费开源交互组件、本地数据持久化、PWA 安装清单与离线缓存

## 本地运行

需要 Node.js 18 或更高版本。

首次运行先安装依赖：

```bash
npm install
```

```bash
npm start
```

打开 <http://localhost:4173>。

运行测试：

```bash
npm test
```

生成可独立发布的静态资源包（包含 Ionic 运行资源）：

```bash
npm run build
```

输出位于 `dist/`，构建过程不会删除已有文件。
