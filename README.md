# 今日兑现

一个手机优先的响应式 PWA 学习助手，帮助用户围绕“计划任务 → 专注倒计时 → 节点反馈 → 完成复盘”兑现每日学习目标。

## 当前版本

P1 可运行版本已实现：

- 默认三个今日任务位，支持新增、编辑和删除
- 新增任务预计时长不可超过当日 24:00
- 同一时间仅允许一个任务进行中
- 秒级专注倒计时与普通暂停额度
- 每任务最多十个可编辑节点，自动计算完成进度
- 无节点任务支持直接完成
- 已开始任务删除时二次确认，并保留主动放弃记录
- 本周红、黄、绿日历状态与今日专注汇总
- “今天 / 日历 / 复盘 / 我的”手机底部导航结构
- 剩余时间不超过 30 分钟且进度低于 60% 时的一次性临期预警
- 可配置的督促风格、愧疚文案开关与减少动画设置
- 自定义奖励池、完成后三选一领取、奖励记录与阶段奖励
- 自定义安全惩罚池及未按时创建任务的随机约束
- 任务失败后一次诚信申辩、黄色待补和跨日期补做
- 日总结、月度完成率与异常统计
- 每累计 7 个绿钩日解锁 1 张自由日卡
- 本地数据持久化、PWA 安装清单与离线缓存

## 本地运行

需要 Node.js 18 或更高版本。

```bash
npm start
```

打开 <http://localhost:4173>。

运行测试：

```bash
npm test
```
