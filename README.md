# 今日兑现

一个手机优先的响应式 PWA 学习助手，帮助用户围绕“计划任务 → 专注倒计时 → 节点反馈 → 完成复盘”兑现每日学习目标。

## 当前版本

P0 可运行版本已实现：

- 默认三个今日任务位，支持新增、编辑和删除
- 新增任务预计时长不可超过当日 24:00
- 同一时间仅允许一个任务进行中
- 秒级专注倒计时与普通暂停额度
- 每任务最多十个可编辑节点，自动计算完成进度
- 无节点任务支持直接完成
- 已开始任务删除时二次确认，并保留主动放弃记录
- 本周红、黄、绿日历状态与今日专注汇总
- 本地数据持久化、PWA 安装清单与离线缓存

## 本地运行

需要 Node.js 18 或更高版本。

```bash
npm start
```

打开 <http://localhost:4173>。

运行测试：

```bash
npm test
```
